# LgpdRecords

Filament plugin for laravel-lgpd-records: manage your LGPD records of processing activities (ROPA, art. 37) from the panel and export them joined with the personal data inventory.

## Installation

You can install the package via composer:

```bash
composer require jeffersongoncalves/filament-lgpd-records
```
